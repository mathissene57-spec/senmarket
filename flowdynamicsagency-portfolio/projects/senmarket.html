SenMarket

La marketplace qui connecte les commerces sénégalais au digital. SenMarket est pensée pour connecter les commerçants sénégalais et leurs clients, notamment autour du commerce entre le Sénégal et la diaspora.

CatégorieMarketplace
FrontendVanilla JavaScript
BackendSupabase
Base de donnéesPostgreSQL
CommunicationWhatsApp Business
Le problème

Un catalogue dispersé, des commandes difficiles à suivre.

De nombreux commerçants vendent encore principalement via WhatsApp, Facebook, Instagram, appels téléphoniques et commandes manuelles.

  • WhatsApp
  • Facebook
  • Instagram
  • Appels téléphoniques
  • Commandes manuelles
La solution

Une plateforme pensée pour le commerce réel.

  • Créer des boutiques
  • Publier des produits
  • Gérer les catalogues
  • Afficher les prix dans différentes devises
  • Gérer un panier
  • Créer des commandes
  • Rediriger vers WhatsApp Business
  • Gérer les boutiques depuis un dashboard
  • Gérer les stocks
  • Préparer l'évolution vers le POS
  • Préparer la monétisation par abonnement
Architecture

Une architecture pensée pour évoluer.

SenMarket n'est pas seulement une marketplace. Le projet évolue vers un système de commerce unifié.

Frontend

  • Vanilla JavaScript

Backend

  • Supabase

Database

  • PostgreSQL

Authentication

  • Supabase Auth

Storage

  • Supabase Storage

Commerce

  • Panier + commandes + POS

Communication

  • WhatsApp Business
Une vision plus large

Marketplace + Boutique physique + WhatsApp + Vente manuelle + POS, dans un même système de vente.

Résultat

Une base technique capable d'évoluer progressivement.
