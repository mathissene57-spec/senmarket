# Documentation client (Étape 6)

Documentation pratique destinée aux utilisateurs réels de la plateforme
(désormais connectée au vrai backend Supabase, plus les maquettes de
l'étape 3) — produite dans le cadre du chantier de finalisation V1
(sécurisation, durcissement, préparation commerciale).

| Fichier | Public | Contenu |
|---|---|---|
| `01-guide-operateur.md` | Opérateur (dashboard) | Créer son compte, ajouter des chauffeurs, configurer les zones tarifaires, suivre l'activité |
| `02-guide-chauffeur.md` | Chauffeur (app mobile) | Connexion par SMS, disponibilité, accepter/suivre une course |
| `03-note-securite.md` | Décideur côté opérateur | Résumé non technique du travail de sécurisation et des limites connues avant ouverture au public |

Ces documents supposent que la Phase 1 (construction technique, voir
`../04-dossier-commercial/02-proposition-deploiement-pilote.md`) est
terminée et que la plateforme tourne sur le vrai backend — c'est le cas
depuis ce chantier.
