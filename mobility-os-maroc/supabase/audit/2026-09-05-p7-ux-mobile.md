## PWA : corrige (gap reel trouve et ferme)

**Constat avant correction** : l'app avait deja un service worker
fonctionnel (`public/sw.js`, notifications push) mais **aucun
`manifest.json`**, aucune reference a un manifest dans `app/layout.tsx`,
aucune icone (`public/` ne contenait que `sw.js`). Consequence concrete :
l'app n'a jamais pu proposer "Ajouter a l'ecran d'accueil" sur
Android/iOS -- un manque reel pour des chauffeurs/passagers senses
l'utiliser au quotidien comme une app native.

**Corrige** :
- `public/manifest.json` (nom, icones, `display: standalone`,
  `theme_color`/`background_color` alignes sur la couleur de marque par
  defaut de la plateforme `#101B3D`/`#FF7A28`, memes valeurs que les
  defauts de `provisionner_operateur`).
- Icones generees (`public/icons/icon-192.png`, `icon-512.png`,
  `icon-maskable-512.png`, `apple-touch-icon.png`) -- glyphe simple (un
  "M" stylise) genere programmatiquement (Pillow), aucune ressource
  externe recuperee (reseau bloque de toute facon).
- `favicon.ico` ajoute (absent jusqu'ici).
- `app/layout.tsx` : `metadata.manifest`, `metadata.icons`, et un export
  `viewport` (theme-color, viewport-fit=cover pour les encoches). **Pas**
  de `maximumScale=1` : bloquer le zoom degraderait l'accessibilite
  (WCAG 1.4.4) pour un gain "app native" marginal.

**Verifie** (serveur de dev local, sans reseau externe) :
`/manifest.json`, `/icons/icon-192.png`, `/sw.js` repondent tous 200 ;
`<link rel="manifest">` et `<meta name="theme-color">` presents dans le
HTML rendu. `npm run build` reste propre apres ces changements.

**Non fait, gap restant honnete** : le service worker ne met en cache
aucun asset (pas de strategie offline-first) -- l'app est installable et
recoit les push, mais ne fonctionne pas hors-ligne. Delibere : mettre en
cache des donnees de dispatch en temps reel comporte un risque reel
(afficher un statut de course perime serait activement trompeur pour un
chauffeur/passager) -- une vraie strategie de cache (Workbox ou equivalent,
cache-first pour le shell statique uniquement, jamais pour les donnees
Supabase) merite sa propre iteration testee en conditions reseau reelles,
hors perimetre de cette passe.

## Reseau (resilience)

Revue de code (pas de test reseau reel possible) : les appels RPC critiques
deja verifies remontent `error.message` a l'utilisateur de facon lisible
(cf. `2026-09-05-p4-p4.5-qa-fonctionnelle.md`) plutot que de planter
silencieusement. `geocoder()` (M-2, proxy `/api/geocoder`) a deja un
`catch` qui retombe sur `null` (pas de coordonnees) sans jamais bloquer le
reste du formulaire. Pas de retry automatique implemente nulle part
(gap mineur, raisonnable pour un pilote).
